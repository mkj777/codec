## Codec
Codec is a lightweight Game Library. Hopefully a Place for everything you need.

### Features
Scanning your PC for all your Games  
Launching them through Codec  
Viewing Details about your Games  
Adding Launch Scripts  

### Installation
Download it from the Website: [Codec](https://codeclibrary.vercel.app/)  
or the latest release "Codec_Installer_x.x.x.exe" from the [Releases](https://github.com/mkj777/codec-releases/releases) section  


### Requirements
Windows 10 or later  

### Development
Codec is a C# WinUI 3 Project using .NET 9.0  
and Inno Setup Compiler to create the installer  

thanks to [Leon Terme](https://github.com/LeMIT2427) for the idea and help with the concept
